## Goal

Framework reutilizavel de som: carrega audio.json, recebe eventos nomeados (SoundEvent) e resolve para sons via tabela (variacoes, pitch/volume aleatorio), com one-shot, loop controlado por parametro (ex. velocidade), som 3D posicional e canais master/musica/efeitos. Todas as fases de audio usam essa API.

## Acceptance Criteria

- [x] Resource do manifesto + tabela evento -> sons em arquivo de dados (nao hardcoded)
- [x] API: disparar evento one-shot, iniciar/atualizar/parar loop com parametros
- [x] Canais master/musica/efeitos com volume nas Game options (game_options.rs)
- [x] Consumidor de SessionMarkerAudio como primeiro uso
- [x] Testes da resolucao evento -> som sem GPU/audio device

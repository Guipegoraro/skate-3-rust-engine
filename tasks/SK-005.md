## Goal

Nova funcao de host `sdk.player.impulse(vetor)` para aplicar um empurrao instantaneo no skatista (boost de um clique). O host guarda o pedido e aplica dentro do tick (depois do update do estado, antes do solve) nos 7 corpos do skate e no esqueleto, so nos estados que aceitam; nos outros retorna erro.

## Acceptance Criteria

- [ ] API documentada em `sdk/skate.lua`
- [ ] Impulso limitado (bounds: finito, modulo maximo, taxa) e so para o jogador local
- [ ] Aplicado dentro de `frame::advance` antes do solve, escrevendo nos 7 corpos do skate + esqueleto (nao em `vector_80`)
- [ ] Estados aceitos na v1: chao/manual (100), powerslide (101), revert (102), ar animado (200); recusa com erro em KnownAir, plants, grind (ou projeta no trilho), a pe, climbing, teleporte, veiculo, replay
- [ ] Testes em `skate-mods` passam
- [ ] Boost acionado por botao do controle no mod do SK-003 (mesmo esquema de botoes livres)

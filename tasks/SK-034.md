## Goal

Alguns NPCs (pedestres/skatistas a pe) andando pelo mapa com modelos ja disponiveis e o ciclo de caminhada, sem fisica nem interacao com o jogador. Primeiro passo para um "LivingWorld" proprio.

## Acceptance Criteria

- [x] Camada de "puppet" reutilizavel extraida do render de jogador remoto (`multiplayer/render.rs`): entidade com modelo + bindings de ossos + pose por frame, sem depender de `Multiplayer`
- [x] N NPCs (configuravel, ex. 5-10) spawnam perto do jogador em chao valido, com modelo stock ou do roster (`custom_models`)
- [x] Tocam `NB_WALK_FWD_CYC` (idle quando parados), com velocidade de caminhada casada com o ciclo (sem patinar o pe)
- [x] Vagueiam por waypoints aleatorios; altura e validade do chao via raycast `ground_below` (normal.y minima, sem degrau grande)
- [x] Opcao em menu/settings para ligar/desligar e escolher quantidade; sem queda de FPS perceptivel com 10 NPCs
- [x] README "Changes in this fork" atualizado

## Goal

Nova funcao de host `sdk.physics.gravity(multiplicador)` para mods mudarem a gravidade do skatista, reversivel ao desativar o mod. Comando proprio (dono unico, separado do trainer) que escala `WorldGravity`, a gravidade processada (`gravity_2648`) e a gravidade do modelo de velocidade do chao; numa segunda fase, as constantes -9,8 fixas.

## Acceptance Criteria

- [x] API documentada em `sdk/skate.lua` e `docs/lua-modding.md`
- [x] Implementada em `crates/skate-mods` + `crates/skate-game/src/modding/`
- [x] Limites (sugestao 0.25..2, nunca zero/negativa) e reset ao desativar o mod / trocar de mapa
- [x] Fase 1: `GamePhysics` guarda a `WorldGravity` base e aplica `base * escala` por tick; `gravity_2648` e `speed_conservation/Gravity` escalados juntos
- [x] Decidido se pulos mantem altura ou velocidade de saida; Fase 2 (constantes fixas do ar/biped/handplant/grind) feita ou registrada como limitacao
- [x] `cargo test -p skate-mods` passa
- [ ] Slider de gravidade no mod do SK-003 (fica para o SK-003)

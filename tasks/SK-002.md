## Goal

Um atalho no Desktop que abre duas instancias do jogo lado a lado, cada uma ocupando metade do monitor (sem borda, parecendo split screen) e presa a um controle, conectadas pelo multiplayer local direto (`--net-host`/`--net-local`). Usa o `bin/skate3rust.exe` normal por padrao; o build release `skate3-multiplayer.exe` fica como opcao.

## Acceptance Criteria

- [x] `.local/play-2p.cmd` -> `scripts/Launch-TwoPlayers.ps1` abre host + convidado com o `bin/skate3rust.exe` (opcao `-Release` usa `bin/multiplayer/skate3-multiplayer.exe`, gerado por `scripts/build-multiplayer-test.ps1`)
- [x] Launcher detecta os slots XInput conectados e passa `--controller` com os dois primeiros; com um controle so, avisa e cai no modo "controle segue a janela com foco"
- [x] Cada instancia com seu `BRP_EXTRAS_PORT` (15703 host, 15704 convidado) e `SKATE3_MODS` apontando para `mods/` do repo
- [x] Convidado sem `--appearance test-uninstalled-outfit`, com `--spawn-offset 2`
- [ ] Menus (Start, navegacao) respondem so ao controle da propria janela (correcao em `customiser.rs:242-243`)
- [x] Janelas posicionadas automaticamente em metade esquerda e metade direita do monitor primario, sem borda (flags `--window X Y W H --borderless` ou, sem codigo, `SetWindowPos` via PowerShell)
- [x] Os dois jogadores se veem e colidem no mesmo mapa; logs em `logs/2p/<data>/`
- [x] Atalho "Skate 3 Rust - 2 Jogadores" no Desktop

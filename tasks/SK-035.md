## Goal

Andar de skate no Terminal do MW2 (mp_terminal), tirado da instalacao do proprio usuario. Caminho: o repo `..\iw4L` exporta o mapa para glTF (`iw4l export-gltf mp_terminal`, ja funciona). Um conversor glTF -> `.skate` gera visual, colisao, spawn e rails, e o mapa abre por `PLAY.bat <mapa>.skate`.

## Acceptance Criteria

- [ ] Receita documentada (`docs/`) para exportar `mp_terminal` com o iw4L, com saida em pasta ignorada pelo git (`data/` ou `maps/private/`).
- [ ] Conversor glTF -> `.skate` (Python com numpy como `tools/asset_pipeline/map_writer.py`, ou Rust), sem precisar de Blender: malhas + instancias de static models, texturas albedo, escala em metros e Y-up.
- [ ] Colisao gerada: malha de visual simplificada (ou clipmap do IW4 via `clipmap_iw4`), sem vidro, folhagem, decals nem superficies nao solidas.
- [ ] Spawn num ponto do chao do terminal (ex.: um spawn `mp_tdm_spawn` do mapa ou o saguao).
- [ ] Pelo menos alguns rails/bordas de grind autorados (corrimaos, bancos, esteiras) como polylines.
- [ ] Mapa abre sem erro e FPS aceitavel (485k triangulos, 580 materiais), screenshot via BRP.
- [ ] Nenhum arquivo extraido do MW2 entra em commit (glTF, texturas, `.skate`); `git status` revisado.
